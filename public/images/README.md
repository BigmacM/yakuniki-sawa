# Image Directory Structure

Place images in these subdirectories to automatically populate the website components:

## /hero/
- `hero-poster.jpg` — Static fallback poster for hero video (recommended: 1920x1080)
- `wagyu-sizzle.mp4` — Looping hero video of sizzling Wagyu

## /menu-gallery/
- `menu-01.jpg` through `menu-11.jpg` — High-resolution scans of actual menu pages
- Naming: zero-padded numbers (01, 02, ... 11)
- Format: JPG, landscape or portrait OK (displayed at 3:4 aspect ratio)

## /experience/
Interior and dining atmosphere shots:
- `interior-1.jpg`, `interior-2.jpg`, `interior-3.jpg`, `interior-main.jpg`
- `dining-1.jpg`, `dining-2.jpg`
- `grill.jpg`
- `sake.jpg`
- `smoke-system.jpg`
- `bar.jpg`
- `private.jpg`
- `entrance.jpg`
- `wagyu-marbling.jpg`

## /food/
High-resolution Wagyu close-up shots:
- `wagyu-marbling-1.jpg` — Close-up marbling shot
- `wagyu-cuts.jpg` — Multiple cuts on display
- `wagyu-grill.jpg` — Meat on the grill
- `wagyu-plated.jpg` — Plated presentation

## OG Image
- Place `og-default.jpg` directly in `/public/images/` (1200x630px)
- Used for Facebook/social sharing previews
